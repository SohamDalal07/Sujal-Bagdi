# Sujal Bagdi - Creator Portfolio Website

Official portfolio website of **Sujal Bagdi** ([@ikkiss_avatar](https://instagram.com/ikkiss_avatar)) from Barwani, MP. Vlogger, digital creator behind the YouTube channel [Campus Life Unfiltered](https://youtube.com/@campus_life_unfiltered), and B.Tech Information Technology student at MPSTME, NMIMS University.

## 🚀 Features

- **Hero Showcase**: Interactive dynamic role ticker and circular avatar.
- **Visual Gallery**: Curated travel adventures, Kalsubai mountain treks, campus stories, and aesthetic night visuals.
- **Thematic Categories**: Showcasing vlogs, reels, performances, and portraits.
- **Featured Works**: Highlighted productions and YouTube series.
- **What I Create**: Live stage coverage, campus fest series, brand partnerships, and adventure vlogs.
- **Memories Section**: Big screen feature honoring the bond with friends:
  > *"One side of me lives to fill every room with laughter, while the other quietly captures the moments, turning wild days into everlasting memories."*
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## 🛠️ Built With

- **HTML5** & **Semantic Markup**
- **Custom CSS3** (CSS Variables, Flexbox, Grid, Responsive Media Queries)
- **Vanilla JavaScript** (Smooth scrolling, reveal animations, mobile navigation toggle)
